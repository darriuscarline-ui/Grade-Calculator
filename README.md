Student grade calculator 
This python program calculates and shows student averages and letter grades
based off 3 grades from the student. It also identifies the top performing
student. 
In order to run this code you need python installed on your computer
open the folder in VS Code
Open the terminal
Run the command "grade_calculator.py"
The features in this program are:
Stores students name and grades using Python dictionary
Calculates each students average grade 
Assigns a letter grade based on the student average
identifies the top performing student 
Counts the number of students with a passing grade
